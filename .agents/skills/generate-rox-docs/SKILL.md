# generate-rox-docs

A page is a JSON page model (`pages/<id>.json`) validated by `rox-dox check` and rendered by
`rox-dox build`. Every claim, node, edge, step and relationship carries a
`source` at the pinned commit; the build refuses stale or missing citations. Author the model
with a script under `pages/authoring/` so it can be regenerated byte for byte.

## Procedure

1. Pin the commit. Every citation points at one rox-core SHA; read files with
   `git show <sha>:<path>`, never the working tree.
2. Read before writing: entry points, k8s/deploy config, models, the README of the folder.
   A claim you cannot cite is not written.
3. Load block-diagram / sequence-diagram / schema-diagram before authoring that section.
4. Fill sections in page order: Related, TLDR, block, schema, sequences. Leave `states`
   empty: state diagrams are deprecated and no longer rendered.
   An empty section stays present and says so.
5. Build, then look at the rendered page before reporting.

## Checks before reporting

- `uv run rox-dox build pages --repo <rox-core> --repo-url https://github.com/Rox-AI/rox-core --out <dir>` succeeds.
- `uv run rox-dox lint-diagrams pages --page <id>` reports 0 errors.
- Open the rendered page; every diagram is readable at full screen.
